# Oleg's Russian Keyboard

给**中国俄语学习者**用的 Windows 俄语输入辅助工具。

它不是输入法，而是在你已有的俄语键盘布局（ЙЦУКЕН）之上加一层：

- **高频词补全** —— 打 `прив` 就提示 `привет`
- **拼写更正** —— 打 `привт` 提示 `привет`
- **变格提示** —— 打完 `другу` 告诉你这是「与格」，并列出全部词形
- **个人词频记忆** —— 你选过的词下次排前面
- **生词本** —— 一键收藏，导出 Markdown
- **形式词典** —— 查任意词的完整词形表

> 现状：**alpha**。主要在 Word 里实测通过；Chrome、微信等程序里候选条位置可能退化（见「已知限制」）。

---

## 为什么做这个

俄语在 Windows 上不是输入法，是**键盘布局**——装了俄语键盘就能打字，但没有任何"联想"。

而对中文母语者，真正的难点有两个：**打字慢**（一个词要敲五六个字母），和**变格**（知道 `друг`，但写句子时要变成 `другу` 与格、`другом` 工具格）。

所以这个工具按这个顺序帮你：

```
补全  >  拼写纠错  >  词形提示
```

1. **补全**——最常用的一层。打 `прив` 就给 `привет`，按空格直接带走，省下敲字母的时间
2. **拼写纠错**——打错的词给正确形式（`привт` → `привет`）
3. **词形提示**——词打完以后，告诉你它在句子里是什么格、还能变成什么样

不预测下一个词（那需要大规模对话语料），只解决"这个词该长什么样"。

## 使用

### 打字时

切到俄语布局，正常打字。停顿约 0.3 秒后，光标下方会弹出候选条。

**助手会跟着布局自动开关**：

- 切到俄语 → 状态条提示「俄语布局 · 助手已就绪」，托盘图标变亮
- 切到中文/英文 → 候选条立即收起，托盘图标变暗，标题显示「待命」

不用手动开关，也不会在你打中文时乱弹。

| 按键 | 作用 |
|---|---|
| **空格** | 选 1 号候选（只在"你还没打完"时接管，见下） |
| `1` – `6` | 直接选第几个候选 |
| `←` `→` | 移动高亮 |
| **`Enter`** | **保留你已打的字母不变**，只补一个空格并收起候选条 |
| `←/→` 之后再 `Enter` | 确认高亮的那一项（动过高亮时回车才换词） |
| `Tab` | 在「补全」和「变格」两种视图间切换 |
| `Ctrl+D` | 把当前词加入生词本 |
| `Ctrl+L` | 查这个词的完整词形表 |
| `Esc` | 关掉候选条 |

> 注意：候选条显示期间，`Enter` / 空格 / 数字键 / 方向键会被程序接管。想换行请等它自动消失（约 1.5 秒）或按 `Esc`。

### 两个自动习惯

**① 选完词自动补空格**

不管用空格、数字键、还是 Enter 选词，插入后都会自动跟一个空格，不用再敲。

**② 首字母自动大写**

- **句首**自动大写：句号、问号、感叹号、换行之后的第一个词
- **专有名词**自动大写：人名（`анна` → `Анна`）、地名（`москва` → `Москва`）、机构名
  —— 用词形分析判断，不是靠词表，所以 `вера`（信仰）不会被误当成人名 `Вера`

两个都能关，见下面「配置」。

### 空格会接管吗

只在**1 号候选比已打的词常见 3 倍以上**时才接管——否则你打完整词按空格会被换成更长的词：

| 已打的词 | 1 号候选 | 空格 |
|---|---|---|
| зав (#10470) | зависеть (#892) | 接管 → `зависеть ` |
| суббот (#81949) | суббота (#2076) | 接管 → `суббота ` |
| завтра (#934) | завтрак (#2931) | 放行，正常空格 |
| друг (#95) | другой (#42) | 放行，正常空格 |

### 托盘菜单

右下角「Я」图标，右键：

- **暂停 / 继续**：暂时关掉候选条（默认双击图标）
- **生词本…**：查看收藏的词，右侧显示词形表
- **查词…**：打开形式词典
- **编辑规则卡…**：改规则不用重新打包
- **显示状态条**：把底部状态条叫回来
- **打开日志文件夹**
- **退出**

> Windows 11 默认会把新图标折叠进任务栏的 **「^」** 里。
> 想让它常驻：设置 → 个性化 → 任务栏 → 其他系统托盘图标 → 把
> `Oleg's Russian Keyboard` 打开。

### 状态条

启动时屏幕**底部居中**会显示一条状态，几秒后**自动消失**（不挡视线）。

想再看：托盘菜单 → 显示状态条。

**状态条上右键也能操作**（暂停 / 生词本 / 查词 / 隐藏 / 退出）——
托盘图标找不到时的备用出口。

### 怎么退出

三种都行：

1. 托盘图标右键 → **退出**
2. 底部状态条右键 → **退出**（状态条消失了就从托盘叫回来）
3. 任务管理器结束 `OlegsRussianKeyboard.exe`

关闭后托盘图标立即消失，没有后台残留。

### 数据在哪

```
%APPDATA%\OlegsRussianKeyboard\
    app.log          运行日志
    settings.json    界面与排除程序设置
    rules.json       规则卡（存在时优先于内置版本）
    user_freq.json   个人词频记忆
    wordbook.json    生词本
    生词本.md        生词本导出（可直接粘到笔记）
```

**全部本地，不联网，不上传任何输入内容。**

### 自定义规则卡

托盘菜单 → **编辑规则卡…** 会自动把内置规则复制到 `%APPDATA%\OlegsRussianKeyboard\rules.json` 并打开记事本。

改完**重启助手**生效。格式：

```json
{
  "cards": [
    {
      "id": "unique-id",
      "title": "看到的中文提示",
      "pattern": "正则表达式",
      "why": "为什么错",
      "fix": "怎么改"
    }
  ]
}
```

`pattern` 是正则，会对整句做匹配。这条机制意味着**改规则不用重新打包 exe**。

### 配置

同目录下的 `settings.json`：

```json
{
  "font_size": 22,
  "exclude_apps": ["game.exe", "some_app.exe"],
  "font_px_by_app": { "msedge.exe": 24 }
}
```

- `font_size`：候选条字号（像素）。**默认 22，固定不变，不跟随正文**
  （之前的"跟随正文"会在不同程序间忽大忽小，已废弃）
- `exclude_apps`：这些程序里不弹候选条（密码管理器已默认排除）
- `font_px_by_app`：按程序单独指定字号，优先级高于 `font_size`

**调字号最省事的办法**：托盘图标右键 → **候选字号** → 增大 / 减小。
改完立刻生效并自动写回 `settings.json`，不用重启。

### 候选条的顺序

```
补全  →  更正  →  变格
```

- 列表里先给**补全**（你打 `прив`，先给 `привет / привести …`）
- 只有当你打错的词**不再是 3 个以上词的前缀**时，才出现**更正**
- 当前没有可补全的时候，自动切成**变格表**；两者都有时 `Tab` 切换

## 已知限制

- **只在 Word 里充分测试过**。其他程序的光标位置探测会退化到"鼠标位置"或"控件矩形"
- **Chromium 系程序**（Chrome / Edge / 微信）常常拿不到光标坐标，需要开启 accessibility 或只能退化
- **密码框**：已用 UIA 检测 `IsPassword` 排除，但这依赖程序正确暴露该属性
- **不是系统输入法**：候选条是独立窗口，无法像微软拼音那样嵌在应用内部（那是 TSF 的工作，见 Roadmap）
- 只支持 Windows 10/11 x64
